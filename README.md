# Timo-In/homebrew-tap

Personal Homebrew Tap for developer tools and macOS applications.

## How to Install

First, add this tap to your Homebrew environment:

```bash
brew tap Timo-In/tap
```

Then, you can install any formula or cask provided by this tap:

### Casks (GUI Applications)

- **later**

  ```bash
  brew install --cask later
  ```

### Formulae (CLI Tools)

- **autossh**

  ```bash
  brew install autossh
  ```

## Update & Maintenance

To update the formulae/casks in this tap to the latest versions:

```bash
brew update
brew upgrade
```
